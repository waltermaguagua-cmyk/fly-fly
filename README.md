# 太空飞机游戏：苍穹裂隙（Python + Pygame）

一个炫酷大气的 2D 太空飞机射击游戏，包含：

- 3 个普通关卡（第1~3关）
- 1 个 BOSS 关卡
- 3 种不同特性的武器可随时切换

## 运行方式

```bash
pip install pygame
python game.py
```

## 操作说明

- 移动：`WASD` 或方向键
- 射击：`SPACE`
- 武器切换：`1` / `2` / `3`
- 失败/胜利后重新开始：`R`

## 武器特性

1. **迅影机炮**：高射速、低单发伤害，稳定输出。
2. **霰爆脉冲**：散射多弹丸，近距离覆盖强。
3. **穿甲激光**：高伤害、可穿透，射速较慢。

## 关卡节奏

- 普通关需要击落指定数量敌机后进入下一关。
- 第三关结束后进入 BOSS 战。
- 击败 BOSS 即通关。
